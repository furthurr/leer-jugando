# Historial de cambios

## [v0.1.0] - 2026-10-11

### Funcionalidades
- Primera publicación de Leer jugando, un juego infantil para aprender a leer en español por el método silábico.
- Recorrido progresivo de vocales, sílabas, palabras, frases y cuentos, con instrucciones habladas.
- Mapa de niveles, estrellas, perfil y progreso guardados en el navegador.
- Zona de adultos para ajustar volumen, gestionar el perfil y reiniciar el progreso.
- Audios MP3 incluidos y uso local mediante `index.html`.

### Publicación
- Acceso web mediante https://furthurr.github.io/leer-jugando/.
- Despliegue automático en GitHub Pages al actualizar `main`, previa ejecución de pruebas y verificación de audios.
- Publicación limitada a los archivos del juego: HTML, CSS, JavaScript, imágenes y audios.

### Verificación
- 112 pruebas automatizadas de lógica, interfaz y herramientas de audio.
- Los 323 audios requeridos están presentes.
